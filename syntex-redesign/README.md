# Syntex Technologies — Enterprise Redesign

A distinctive, premium enterprise ICT systems-integrator identity for Syntex
Technologies (Windhoek, Namibia), built on Vite + React 18 + React Router 6.

## Run
```bash
npm install
npm run dev
```

## What's inside
- `src/` — full app (shell, components, pages, styles, verified data)
- `qa/` — console audit script + manual checklist
- `IMPLEMENTATION_REPORT.md` — the 9-section report
- `FILE_MANIFEST.md` — every file mapped to what it does
- `INTEGRATION.md` — how to merge into your existing repo
- `../syntex-patches/` — targeted patches for your ORIGINAL files
